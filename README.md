# Shared Table AR Cards

A spatial card-game prototype for Snap Spectacles, built in Lens Studio.

## Experience

The Lens places a fan-shaped player hand and a shared discard pile around a virtual tabletop. The design explores card play in the user's surrounding space, with an automated opponent standing in for multiplayer.

## Project files

Open `first.esproj` in Lens Studio. The project uses TypeScript, Spectacles Interaction Kit, and SpectaclesUIKit. Planning and build notes are in `devpost/`.

## Validation status

The latest acceptance report records a successful TypeScript compile and a clean preview launch with the initial seven-card hand. It also records that drag behavior could not be retested after the visual changes and that the eleven-card layout was not reached in that validation pass. See `devpost/acceptance-report.md` for details.
